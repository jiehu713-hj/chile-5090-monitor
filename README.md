# 智利圣地亚哥 RTX 5090 监控

## 部署到固定公网地址（Render）
1. 在 GitHub 新建仓库（例如 `chile-5090-monitor`）。
2. 将本项目根目录内的 `app.py`、`index.html`、`requirements.txt`、`render.yaml` 上传到仓库根目录（不要把它们放到多一级子目录）。
3. 登录 https://dashboard.render.com/ ，选择 **New > Blueprint**，连接刚建立的 GitHub 仓库。
4. 核对 `render.yaml`；它会创建一个 `starter` 付费档 Python Web Service。确认费用后执行部署。
5. Render 提供固定的 `https://...onrender.com` 地址。访问 `/api/health` 确认返回 `ok: true`，再访问 `/api/data` 验证检查结果。

## 重要说明
- 此程序每30分钟巡检一次，并不是真正毫秒级实时数据。
- 库存判断只基于公开商品网页的购买按钮等信号，**不能代替向商家确认现货数量**。SoloTodo 是比价来源，不代表门店现货。
- 遇到验证码、访问限制或页面结构改变，会标记检查失败，不会将其识别为缺货。
- 数据库默认为本地 SQLite 文件。**Render 的非持久化文件系统在重启/重新部署后可能清空历史记录**。要长期保留价格历史，需要额外挂载持久磁盘或迁移到托管数据库；使用前应确认相应资费。
- 网页内提醒要求网页处于打开状态；关闭网页后不会自动发送手机推送。
- 请遵守目标站点的访问条款、限流规定，并定期核对监控链接。

## 四地升级说明
- 智利 CLP、台湾 TWD、马来西亚 MYR、加拿大 CAD；价格不可直接跨币种比较。
- “搜索/比价”“整机”“限整机购买”的页面明确区分，不代表单卡可批量下单。
- 当前价格阈值功能仅对智利 CLP 生效。
- 部分网站可能反爬；显示检查失败而不是库存为零。
- 覆盖 GitHub 根目录的 app.py 与 index.html，Render 自动部署后生效。
